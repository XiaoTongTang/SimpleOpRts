场景：20×20 格空图，中间放一块 3×3 实心墙；另有一张图放「3 格长、1 格厚」的横墙。

| ID   |   行 | 断言原文                          | 它守的业务规则                                | 怎么验的                                     | 结论                                           |
| ---- | --: | ----------------------------- | -------------------------------------- | ---------------------------------------- | -------------------------------------------- |

| W-02 |  59 | 默认 8 px 网格上正好切满一格（与沙盒一致）      | 默认比例尺下，切线从格的一个角连到对角——这就是沙盒里看到的墙角       | `chamferDepthPx(8) === 8`                |                                              |
| W-03 |  60 | 24 px 网格上仍然只切 8 px（不随格长放大）    | **换格长不许改切角**（否则"比例尺实验"里混进"墙角被啃多狠"这个变量） | `chamferDepthPx(24) === 8`               |                                              |

| W-05 |  65 | 厚墙内部格 mask = 0（不切）            | 四面都被墙包住的格，不该有任何一个角被切                   | 3×3 方块中心格，`getWallChamferMask === 0`     |                                              |
| W-06 |  67 | 厚墙内部格还是完整方块                   | 不切的格保留原样                               | 返回多边形是 4 个顶点                             |                                              |
| W-07 |  68 | 内部格的左上角还在                     | 用几何验"没被切"，比顶点数更接近业务                    | 点 (格左上角 +1, +1) 落在多边形**内**               |                                              |
| W-08 |  70 | 3×3 左上角格只切左上这一个角              | 暴露角判定：只有"两条正交邻格都是空地"的角才切               | `mask === 1`（bit0 = 左上）                  |                                              |
| W-09 |  73 | 左上那个角真的没了                     | 裁剪真的发生了，不是只在掩码上记账                      | 左上角 +1,+1 的点在**外**                       |                                              |

| W-11 |  81 | 1 格厚墙中段 mask = 0（不切）          | 一堵 1 格厚的墙上，中间的格左右都是墙 → 没有暴露角           | 横墙中段格 `mask === 0`                       |                                              |
| W-12 |  82 | 1 格厚墙端头 mask = 左上 + 左下（两个角都切） | 端头的上下两侧都是空地 → 两个暴露角                    | `mask === 9`（bit0 + bit3）                |                                              |
| W-13 |  85 | 非墙格返回 null                    | 空地不存在"墙体多边形"这种东西，调用方要能明确区分             | 空地格 → `getChamferedCellPolygon === null` |                                              |

## [1b] 换格长不改切角（3 条）

场景：同一块 3×3 墙，格长换成 **24 px**。若深度还是"1 格"，切线会切到对角（24 px）；实际应只切 8 px。

| ID   |   行 | 断言原文                             | 它守的业务规则            | 怎么验的                | 结论                             |
| ---- | --: | -------------------------------- | ------------------ | ------------------- | ------------------------------ |
| W-14 |  99 | 角上 2 px 处已经被切掉（8 px 深度覆盖到）       | 换了格长，角**确实还在切**    | 距角 (2,2) 的点在**外**   | 换格长会变动切角的大小，因为切角从来不看格长，是固定切掉半格 |
| W-15 | 100 | 角上 10 px 处还在（深度只有 8 px，不是 24 px） | 切掉的量是 8 px，不跟着格长放大 | 距角 (10,10) 的点在**内** |                                |
| W-16 | 101 | 格心在                              | 切角不会把格子切穿          | 格心在**内**            |                                |

## [4] 不穿墙压力测试（6 条 = 2 场景 × 3 档半径）

判定方式（两个场景相同）：逐帧对所有船求「与墙的接触深度」，只要有一艘 `depth > 1e-6` 就算这一帧穿了；
**穿透帧数必须为 0**。

【评审】穿墙压力测试不应当放在“切角”中；这个规则与切角完全无关，是碰撞要管的事情；如果碰撞处理的逻辑已有这个压测，则删除这里；若没有则挪过去；
