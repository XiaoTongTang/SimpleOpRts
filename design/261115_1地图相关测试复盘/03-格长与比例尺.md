> ⚠️ **本文档整体作废（2026-11-15）**：这里的 45 条断言是按**错误口径**（格长 = 分辨率、世界尺寸恒定、
> 导入要重采样）写的，其中 `C-17…C-24`（重采样）、`C-40…C-45`（运行时换格长命令）已随实现删除，
> `C-26…C-39` 的"文件 px 口径"也改成"文件 width/height 是格数"。
>
> **请改为评审 [05-技术设计-格长即比例尺.md](05-技术设计-格长即比例尺.md)**；
> 现行的 `cell-size.smoke.mjs` 已按它重写（49 条），口径是"格数是权威、世界尺寸 = 格数 × 格长"。
> 本文档保留只为记录当时的误解。

> 被测对象：`src/core/map.js`（`DEFAULT_CELL_SIZE` / `clampCellSize` / `regridMap` / `parseMapDocument`）、
> `src/core/core.js`（`GameCore({ cell })`）
>
> 唯一要守的规则：**格长只有一个来源——代码里的 `DEFAULT_CELL_SIZE`**，任何入口（包括导入的地图文件）都改不动它。

## [1] 夹值（8 条）

| ID | 行 | 断言原文 | 它守的业务规则 | 怎么验的 | 结论 |
|---|---:|---|---|---|---|
| C-01 | 34 | 默认格长是个正数 | 常量没被误设成 0 / 负数（会把网格算成 0 列） | `DEFAULT_CELL_SIZE > 0` | |
| C-02 | 35 | 合法值原样返回 | 夹值函数不该改动合法输入 | `clampCellSize(16) === 16` | |
| C-03 | 36 | 太小贴下限 | 下限 4 px：更小的格会让一张图几万到几十万格，建一次场几十毫秒 | `clampCellSize(1) === 4` | |
| C-04 | 37 | 太大贴上限 | 上限 64 px：再大就基本没有网格可言 | `clampCellSize(9999) === 64` | |
| C-05 | 38 | 小数取整 | 格长必须是整数（网格下标靠它算） | `clampCellSize(12.6) === 13` | |
| C-06 | 39 | 垃圾输入回默认 | 手改代码写错类型时不至于把整个游戏搞崩 | `clampCellSize("abc") === DEFAULT_CELL_SIZE` | |
| C-07 | 40 | 0 回默认 | 同上（0 会让 cols = Infinity） | `clampCellSize(0) === DEFAULT_CELL_SIZE` | |
| C-08 | 41 | 格式基准格长没被改成可调项 | 地图**文件格式**的基准是 8 px/格；改它等于改所有旧地图文件的含义，所以它不该跟 `DEFAULT_CELL_SIZE` 一起浮动 | `MAP_FILE_CELL === 8` | |

## [3] `regridMap` 重采样（8 条）

场景：2000×1200 世界、格长 8（250×150），在 x=1000 起画一堵 **32 px 厚**的竖墙；再重采样到 16 / 24。

| ID | 行 | 断言原文 | 它守的业务规则 | 怎么验的 | 结论 |
|---|---:|---|---|---|---|
| C-17 | 76 | 世界宽不变 | 重采样只换分辨率，不改世界尺寸 | `m16.width === 2000` | |
| C-18 | 77 | 世界高不变 | 同上 | `m16.height === 1200` | |
| C-19 | 78 | 格长换了 | 真的换了 | `m16.cellSize === 16` | |
| C-20 | 79 | 列数按新格长 | 网格跟着重算 | `m16.cols === 125` | |
| C-21 | 85 | 墙还在同一片世界坐标上（32 px 正好 2 格） | **重采样不挪墙**：32 px 厚的墙在 16 px 格上应正好占 2 列，且落在那片世界坐标 | 收集有墙的列号 → `"62,63"` | |
| C-22 | 88 | 不整除时列数向上取整 | 2000/24 有余数时的边界处理 | `m24.cols === ceil(2000/24)` | |
| C-23 | 91 | 最后一列不会整列变墙（采样点被夹进世界内） | 采样点越界会被当成墙 → 右侧凭空长出一条墙带（这是踩过的坑） | 24 px 时最后一列有墙的格数 = 0 | |
| C-24 | 93 | 格长没变就返回原图 | 不白拷一份（纯实现细节，无业务含义） | `regridMap(m8, 8) === m8` | |
