# 软化 Couzin 模型：五分钟看懂参数

> 配套可玩原型：`prototype/couzin-command.html`（按 `H` 可以切换软化和原始版对比）
> 读完这篇，你应该能说清：**三个圈和一个数字，各自在管什么。**

---

## 一句话

这套模型只回答两个问题：

> **你和身边人保持什么距离？你更听指挥，还是更听邻居？**

三个圈回答第一个，一个数字回答第二个。

---

## 一、从鱼群说起

2000 年前后，生物学家 Iain Couzin 研究鱼群时注意到一件反直觉的事：

**鱼群游得那么整齐，但没有一条鱼在指挥。**

每条鱼只看身边几条同伴，只做三件事：

1. 太近了 → 躲开
2. 不远不近 → 跟着游同一个方向
3. 有点远了 → 往回靠

这三件事对应三个套在一起的圈。就这么简单，整群鱼就动起来了。

这个模型后来被大量用于电影和游戏里的群体动画——因为它**用三条规则生成了一万条规则的效果**。

---

## 二、为什么要"软化"

原始模型有个硬伤：三个圈是**互斥的**。

```
最近的圈里有鱼   → 只躲，别的都不管
否则中间的圈有鱼 → 只跟方向
否则远处的圈有鱼 → 只往回靠
否则            → 才轮得到"我想去哪"
```

看出来了吗——**"我想去哪"排在最后，而且要前面三个条件全不成立才轮得到它。**

放到游戏里就是灾难：部队只要抱团，每个单位身边必定有邻居，于是它**永远走不到"否则"那一行**。你点的移动命令，权重恒等于零。

**软化**就是把硬边界换成一条"越近越强"的力度曲线，让四个力同时在场、按权重相加：

```
总力 = 分离力 + 对齐力 + 凝聚力 + 命令力
          ↑        ↑        ↑        ↑
        纪律      协同     凝聚     服从度
```

原来的"红绿灯"变成了"重力场"。命令终于有了一席之地。

## 三、三个圈

### r₁ 排斥区 —— 你的私人空间

**管什么**：多近算"撞上了"。

像电梯里人一多，你会不自觉把肩膀往后收半寸。没人教你，但所有人都这么干。

| 调大 | 调小 |
|---|---|
| 队形松散、占地大、不易被一发范围伤害全打中 | 挤成一团、视觉穿模 |
| 但互相推挤的力变强，**整支部队反而走不快** | 转向时互相卡住、容易堵死 |

这个参数在系统里**替代了碰撞体**——这套模型没有真正的碰撞检测，r₁ 就是它们的体积。

### r₂ 定向区 —— 你会跟谁的风

**管什么**：多远的人会影响你"朝哪个方向走"。

过马路时你其实很少看红绿灯，更多是**跟着前面那群人走**。定向区只改方向，不改位置。

| 调大 | 调小 |
|---|---|
| 队伍整齐、像方阵 | 各自为战、灵活 |
| 但也**僵**：全队会一起犯同一个错 | 队形碎，容易变成一盘散沙 |

这个圈基本就是"乌合之众 ↔ 精锐方阵"的旋钮。

### r₃ 吸引区 —— 别走散的极限

**管什么**：多远还算"我们是一伙的"。

逛街时你走神了，一抬头看不见同伴，会停下来回头找。超过某个距离，你就**断线**了。

| 调大 | 调小 |
|---|---|
| 部队拉得很开还能保持整体 | 容易裂成几块、各打各的 |
| 但远处单位仍在互相拉扯，**反应迟钝** | 断开即自由 |

它有个隐藏身份：**通信半径**。超出这个圈的单位感知不到你——想让"部队被切断"成为真实事件，把它调小就有了。

---

## 四、那个数字：ω 服从度

它不在距离轴上，因为它是**权重**，不是"多远"。

**管什么**：命令和"邻居的意见"，你更听谁的。

想象一个导游举着小旗，和一股自己流动的人潮。ω 就是旗子的说服力。

| ω | 什么感觉 |
|---|---|
| 0 | 旗子只是装饰，没人看 |
| 0.3 | 听见了，但不照做 |
| **1.1** | **听话，但保留群体的自然感**（推荐起点） |
| 1.5+ | 像磁铁吸铁屑：都去了，但队形散了 |

**它最微妙的地方**：ω 的实际效果取决于队形密度。人越挤，邻居的意见越响，同一个 ω 就越不管用。

这不是 bug，是模型自带的性质——**越挤越难指挥**。

所以 ω 不该是固定值。它该随纪律、通信状态、老兵经验变化。部队失联时 ω 掉到 0，它们自动进入"自主模式"。

## 五、四种社交距离（一张表记住）

| 距离 | 态度 | 参数 |
|---|---|---|
| 太近 | 我不想和你重叠 | r₁ 排斥区 |
| 中近 | 我要和你同向 | r₂ 定向区 |
| 中远 | 我要和你在一起 | r₃ 吸引区 |
| 太远 | 我看不见你 | 圈外 |

---

## 六、比例比数值重要

三个圈要满足 **r₁ < r₂ < r₃**，经验比例大约 **1 : 2 : 4**（原型默认 24 : 52 : 96）。

打破顺序会出事：

| 破坏 | 后果 |
|---|---|
| r₂ < r₁ | 定向圈被排斥圈吃掉 → 彻底散沙 |
| r₃ < r₂ | 吸引圈消失 → 部队永远聚不拢 |
| r₃ 远大于 r₁ | 松散大阵，但转向像拖船 |

---

## 七、按现象反查

| 你看到的现象 | 该动谁 |
|---|---|
| 挤成一坨 | r₁ 调大 |
| 老是碎成几块 | r₃ 调小 |
| 整齐得像一块铁板 | r₂ 调小 |
| 各走各的、没有队形 | r₂ 调大 |
| 命令没人理 | ω 调大 |
| 命令太生硬、没群体感 | ω 调小 |
| 走到一半散了 | r₃ 调小 或 ω 调大 |

---

## 八、顺带一提：屏幕上颜色是什么

省得你猜——**颜色是这个单位此刻的"服从度份额"**。

蓝色 = 命令没参与，全靠邻居在动；橙色 = 命令占了上风；中间经过紫色。

所以被夹在队伍中间的单位偏蓝，冲在最前、身边没人的单位偏橙。不是随机染色。

注意它和 ω 不是一回事：**ω 是你给的强度，颜色是实际竞争出来的结果。**

---

## 九、记住这一句

> **三个圈决定你和别人怎么相处，ω 决定你有多听指挥。**
