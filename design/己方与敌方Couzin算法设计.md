## 目标

为了实现两个互相敌对的势力之间的交战行为，需要额外增加Couzin模型的“战斗参数组”

## 实现方法

为目前的Couzin模型添加一套 ”战斗参数组“，包括 ”r4威胁“ 区与 ”r5寻敌“ 区 和这两个区对应的权重 ”威胁权重 w4“ ”寻敌权重w5“

单位仅会与非己方阵营的单位计算”战斗参数组“的力，同一阵营间不计算；

敌对单位距离 Denemy

**设计意图**

| 距离 | 行为 |
|---|---|
| Denemy > r5 | 不计算力 |
| r4 < Denemy < r5 | 试图接近敌对 |
| Denemy < r4 | 试图远离敌对 |

---

## 一、力的实现：用软核，不要硬边界

上面三条是**意图**。但直接写成 `if / else`，会在 `Denemy = r4` 处产生力的突变，导致单位在 r4 上来回震荡：

```
D 略大于 r4 → 全力冲向敌人 → 冲进 r4 内
D 略小于 r4 → 全力后退     → 又退到 r4 外
→ 在 r4 上高频抖动
```

改成两个**平滑交接的权重核**，两者在 r4 处都趋近于 0：

```js
// 寻敌：r5 处满幅，r4 处归零
w_seek(d)   = w5 * smoothstep(r4, r5, d);

// 威胁：d → 0 时满幅，r4 处归零
w_threat(d) = w4 * Math.pow(1 - Math.min(1, d / r4), 2);
```

对应的力（对所有处于 r5 内的敌方单位求和）：

```
对每个敌方单位 e，令 d = |pᵢ − p_e|

F_seek   += (p_e − pᵢ) / d · w_seek(d)
F_threat += (pᵢ − p_e) / d · w_threat(d)
```

效果：单位会**稳定停在 r4 外侧一点点**（两个力在该处等值），既不冲进去，也不抖动。

> `smoothstep(a, b, x)` 为标准三次平滑插值：
> `t = clamp((x−a)/(b−a)); return t*t*(3−2t)`
>
> `(1 − d/r4)²` 与分离力（`sepW`）使用同一个核，保证量纲与手感一致。

---

## 二、参数归属：w4 / w5 由小队状态机输出

`w4 / w5` **不能是全局常量**，否则小队状态机无法控制战斗行为。

它们与 `w_sep / w_coh` 一样，属于小队的**接战态参数组**：
由 L2 小队层每 2~5 Hz 决定目标值，并在 **0.3 s 内插值过渡**，L1 群体层只会看到连续变化的权重。

| 接战态 | w4 威胁 | w5 寻敌 | 行为 |
|---|---|---|---|
| CALM 平静 | 0 | 0 | 战斗参数组完全关闭 |
| ALERT 警戒 | 中 | 低 | 拉开距离、试探 |
| ENGAGE 交战 | 中 | 高 | 主动压上 |
| ROUT 溃退 | 高 | 0 | 只逃不打 |

`r4 / r5` 通常作为**兵种 / 阵营属性**，不随状态变化；
若需要“溃退时不顾一切地远离”，可在 ROUT 态临时放大 `r4`。

---

## 三、职责边界

战斗参数组**只负责走位**，不负责伤害。

命中与伤害是一条独立的线（距离 + 朝向 + 冷却 → 扣血），
不要混进 Couzin 的力里，否则两套系统会互相污染，且都无法单独调试。
