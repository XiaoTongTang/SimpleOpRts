### 社交参数组：

未编队散兵：对同阵营所有单位均计算”凝聚“与”对齐“

已入队单位：仅对自己小队内单位计算”凝聚“与”对齐“

## 战斗参数组
未编队散兵：
- 寻敌：自己计算寻敌方向 else if (d < r5 && sq.loose)
- 威胁方向：自己计算威胁方向 if (d < r4)
已入队单位：
- 寻敌：全队按敌人质心统一寻敌方向（全队读同一个 `squad.target`）
	- 质心： **`1/(d+30)²` 加权质心，且只统计"小队重心 `r₅` 内"的敌人**
	- 强度：离目标远的单位推力大、近的推力小`const w = smoothstep(r4, r5, dT);   // dT = 该单位到目标点的距离` 
- 威胁方向：自己计算威胁方向
