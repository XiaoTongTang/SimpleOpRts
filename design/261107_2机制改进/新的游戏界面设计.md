# 概述

我们来设计整体的战场指挥UI界面与装配构筑界面；

# 战斗指挥界面
在战斗指挥界面中，屏幕核心可视区域就是战场，侧边栏只有每个小队的状态，能在侧边栏点选每个小队给其下达命令，也能在战场上点选或框选（小队标记会出现在小队质心）来选中小队；

# 舰船设计界面
装配界面分为舰船设计界面与小队构筑界面；舰船设计界面的左侧栏显示当前玩家已经创建的所有舰船方案；选中一个舰船方案后，屏幕中央区域会显示这个舰船的船体贴图；右侧栏顶部会显示本舰船的血量，回血，护盾量等等数值；剩下区域显示此舰船每个槽位已经装配的武器与插件；当玩家选中一个武器与插件槽位后，会展开一个二级面板，此面板中枚举了此槽位可以安装的所有武器或插件，以及每个武器、插件的信息；

左侧栏中舰船方案也应当在方案名称左侧显示这个方案的船图；右侧栏装配区中，应当在武器上方区域增加“当前船体”的按钮，这里会显示船体的船图，以及船体模板的名称；武器装配区域，最右侧显示插槽代号，第二个位置显示插槽尺寸，第三个位置显示当前安装的武器名称，最右侧显示武器占用的承载力；另外，屏幕中间的区域的船体展示区域上的武器安装位，应当在槽位为空时才显示W1-空 ，槽位不为空时显示w1-激光 这样；请修改

点击 “当前船体”区域也应当展开船体选择界面，就像武器和插件一样；另外插件槽不需要显示“尺寸” ；另外我希望界面上在船体切换区，武器区，插件区，顶部能有一个小标题做切分；最后目前整个UI界面的按钮，弹窗等，能否用CSS样式改为像素风格？

# 小队构筑界面
小队构筑界面同样是三列布局；左列是所有小队编制模板，选中一个编制模板后，屏幕中央会展示这只小队中的所有舰船；右侧列是编制调整界面，顶部会显示本小队一些信息，包括总血量，总盾量，总dps，人口占用；剩余的部分是显示小队编制内引用了哪些舰船方案，以及这个舰船方案预期有多少条；可以在此处新增，删除小队引用的舰船方案，以及调整每个舰船方案的数量；请于 design\261107_2机制改进 中，用html帮我设计这几个UI的原型
